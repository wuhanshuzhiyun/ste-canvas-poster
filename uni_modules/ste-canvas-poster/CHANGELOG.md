# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 (2026-05-26)

### 首次发布

- Schema 驱动的声明式海报绘制引擎
- 支持微信小程序与 APP 双端
- 内置元素类型：view、image、text、qrcode
- Flex 布局支持（row / column、alignItems、justifyContent）
- 模板变量自动替换 `{{key}}`
- rpx 到 px 自动转换
- 渐变背景（linear-gradient）
- 圆角/边框/阴影
- 文本多行换行、省略号、删除线
- 图片 objectFit（fill / cover / contain）
- 内置二维码生成，无需额外依赖
- 完整 TypeScript 类型声明
